# Калькулятор неустойки по ДДУ и процентов по ст. 395 ГК РФ

Считает две вещи:

- **неустойку застройщика** за просрочку передачи объекта долевого строительства
  (ч. 2 ст. 6 ФЗ № 214-ФЗ), с учётом моратория и потолка ставки по ПП РФ № 326;
- **проценты за пользование чужими денежными средствами** (ст. 395 ГК РФ).

Результат выводится не одной цифрой, а таблицей по периодам: даты, число дней,
применённая ставка, формула, сумма. Такой расчёт можно приложить к иску.

## Что учтено

Ставка для неустойки по ДДУ берётся **на последний день срока передачи** по договору,
а не на дату фактической передачи — позиция ВС РФ № 41-КГ17-26.

По ПП РФ № 326 (ред. от 30.12.2025): дни с 22.03.2024 по 31.12.2025 показываются
отдельной строкой без начисления; для периода с 01.07.2023 по 31.12.2025 ставка
ограничена 7,5%. С 01.01.2026 начисление за новые периоды возобновилось.

Проценты по ст. 395 ГК разбиваются по каждому периоду действия ключевой ставки,
с делителем 365 или 366 в зависимости от високосности года.

## Данные

История ключевой ставки — массив `RATES` внутри `index.html`, дата в каждой строке
означает день вступления ставки в силу. Источник — Банк России,
[cbr.ru/hd_base/KeyRate](https://www.cbr.ru/hd_base/KeyRate/).

Даты берутся только с сайта ЦБ: сводки в поисковой выдаче регулярно путают дату
заседания совета директоров с датой вступления ставки в силу, а для расчёта по
ст. 395 именно она задаёт границы периодов.

## Использование

Одна страница без внешних зависимостей: ни библиотек, ни сетевых запросов, ни
сборки. Открывается двойным щелчком с диска и работает без интернета. Для публикации
достаточно положить `index.html` на любой статический хостинг.

## Оговорка

Калькулятор даёт арифметический расчёт по действующим нормам и не заменяет
юридическую консультацию. Суд вправе снизить неустойку и штраф по ст. 333 ГК РФ.
Проверяйте ставку, период и применимую редакцию по обстоятельствам своего дела.
